# 📦 Gerenciador de Estoque

Aplicação Full Stack desenvolvida para controle e gerenciamento de produtos em estoque, com interface intuitiva, cálculo de métricas em tempo real, busca dinâmica e alertas visuais de estoque baixo.

---

## 🚀 Funcionalidades

- **CRUD Completo de Produtos:** Cadastro, listagem, edição e remoção de itens.
- **Dashboard de Métricas:** Visualização em tempo real do total de produtos cadastrados e valor total do estoque.
- **Alertas de Estoque Baixo:** Destaque visual automático para produtos com quantidade abaixo do limite mínimo definido.
- **Filtro de Busca:** Pesquisa dinâmica por nome ou categoria de produtos.
- **Interface Responsiva:** Desenvolvida em JavaScript puro e CSS adaptável.

---

## 🛠️ Tecnologias Utilizadas

### **Backend**
- **Node.js** com **Express**
- **SQLite** (banco de dados relacional leve)
- **CORS** e **Body-Parser**

### **Frontend**
- **HTML5** & **CSS3**
- **JavaScript (Vanilla JS)**
